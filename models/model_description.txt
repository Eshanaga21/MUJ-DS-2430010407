=== Model Description ===

Model Name: RLFA-CNN (Regularized Lightweight Feature Aggregation CNN)
Framework:  TensorFlow 2.20.0 / Keras
Pretrained: No (trained from scratch)
Task:       Binary classification (Organic vs Recyclable waste)

=== Architecture ===

The RLFA-CNN is a parameter-efficient 3-layer CNN designed for waste
classification. It combines five complementary components:

1. Moderate Data Augmentation (training only)
   - RandomFlip, RandomRotation, RandomZoom, RandomContrast

2. Batch Normalization after each Conv2D
   - Batch Normalization can help stabilize training

3. Global Average Pooling (GAP)
   - Replaces Flatten, reducing parameters from ~4.3M to ~111K

4. L1 Kernel Regularization (lambda=1e-5)
   - L1 regularization encourages sparse weights

5. Adaptive Learning Rate (ReduceLROnPlateau)
   - factor=0.5, patience=2, min_lr=1e-6

=== Baseline Comparison ===

The SimpleCNN baseline uses the same Conv2D layers but with:
- Flatten instead of GAP
- No BatchNormalization
- No L1 regularization
- No augmentation

This results in ~4,287,938 parameters (38.7x more than RLFA-CNN).
